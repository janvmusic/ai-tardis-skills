# Personal Preferences

Preferences that apply to every task, above the skills. Skills say how to do a task. These say how to talk and how to write code.

`AGENTS.md` is the single source: context, pragmatism, language, accuracy, writing style, output formatting and coding rules.

The CLI does not install it. Copy it where your agent reads it:

```bash
cp personal/AGENTS.md ~/.claude/CLAUDE.md   # Claude Code, every project
cp personal/AGENTS.md ./AGENTS.md           # Codex or OpenCode, this project only
```

This repository is the source of truth. Edit here, then copy again.
